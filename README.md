# Block Boom / Блок Бум — Blast Block Puzzle

Мобильная головоломка (жанр Block Blast / Toon Blast): поле 8×8, фигуры из блоков,
тикающие бомбы с круговым фитилём, камни-препятствия (разбиваются со 2-го удара),
50 уровней с 1-3 целями и лимитом ходов, звёзды, монеты, бустеры, главное меню
с настройками (звук/язык), помощью с картинками и ежедневным подарком за вход,
обучающие подсказки, пополнение монет за просмотр рекламы (демо в вебе,
нативно — Yandex Mobile Ads). Языки: RU / EN (автодетект + переключатель).
Полностью работает офлайн (PWA).

## Запуск локально

```bash
bun install        # или npm install
bun run dev        # http://localhost:3000
```

## Деплой на Vercel (5 минут)

1. Создай репозиторий на GitHub и запушь этот код:
   ```bash
   git init
   git add .
   git commit -m "Block Boom 1.5.0"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/blockboom.git
   git push -u origin main
   ```
2. Зайди на vercel.com → **Add New… → Project** → выбери репозиторий → **Deploy**
   (настройки менять не нужно: Next.js определится автоматически).
3. Получишь адрес вида `blockboom-xxx.vercel.app` — это и есть адрес игры
   (HTTPS уже включён, манифест, офлайн и иконки внутри).

## assetlinks.json (после упаковки в PWABuilder)

Когда соберёшь Android-пакет на pwabuilder.com, там покажут SHA-256 отпечаток
твоего ключа подписи. Создай файл `public/.well-known/assetlinks.json`
(шаблон — `assetlinks.example.json` в корне, подставь свой package_name и SHA),
закоммить и запушь — Vercel перепубликует сайт, и приложение будет
открываться без адресной строки.

## Никогда не коммить

- `.env` и любые ключи
- keystore / пароль от него (это подпись приложения — храни отдельно!)

## Что нового в 1.5.0

- **Главное меню:** запускается сразу в меню с кнопками по важности — большая
  кнопка «Продолжить» (под ней текущий уровень), «Выбрать уровень» (открывает
  карту), «Помощь» и «Настройки» (звук и язык). Снизу мелкая статистика:
  пройдено уровней и звёзды. Фон с плавающими блоками и свечением.
- **Ежедневный подарок:** блок в меню — 50 монет раз в день за вход; рядом
  общий счёт монет и три инструмента (молоток / микс / +5 ходов) с покупкой.
- **Помощь:** полное описание игры и каждой механики отдельно (линии и
  множители ×2/×4/×6, бомбы и фитиль, камни, задачи уровня, инструменты,
  монеты и реклама) — с мини-картинками полей. В самой игре — только
  очень краткие подсказки.
- **Обучение в игре (один раз):** на 1-м уровне краткое объяснение, что делать;
  при первом появлении бомбы — как её обезвредить; при первом появлении
  камня — как его разбить. Показываются один раз и запоминаются.
- **Инструменты крупнее с цветной подсветкой** (молоток — красный, микс —
  бирюзовый, +5 ходов — янтарный); если монет не хватает, вместо автопокупки
  открывается пополнение за рекламу.
- **«Пополнить за рекламу»** переехал из карты уровней в блок монет в игре
  и в меню (карта стала чище); надпись «на карту» заменена на понятную
  «Выбрать уровень».
- Багфиксы 1.4.2 в комплекте: фитиль горит непрерывно даже при удержании
  фигуры; бомба в очищаемом ряду (в т.ч. с цифрой 1) обезвреживается без
  взрыва и потери жизни; камень: гладкий → весь в трещинах → разрушен.

## Что было в 1.4.2

- **Фикс фитиля:** раньше, когда брал фигуру в руку, круговая анимация фитиля бомбы
  замирала. Теперь кольцо горит непрерывно — и отсчёт тоже идёт, пока держишь фигуру
  («сидеть» на бомбе нельзя). Пауза только там, где поля не видно: оверлей
  победы/поражения, магазин, реклама.
- **Камни за 2 удара:** изначально камень идеально гладкий; после первого удара
  (очистка ряда с камнем) он весь покрывается сетью трещин; второй удар — камень
  разбивается полностью. Молоток по-прежнему сносит камень одним ударом.
- Прочее: монет за уровень меньше (30+20×звёзды, реплей 10), очки 12 за клетку,
  50 уровней с несколькими целями, цены бустеров 100/150/120, магазин в уровне с
  подтверждением покупки, кнопка «Пополнить +110» за рекламу (веб-демо 5 секунд),
  мост к Capacitor/Yandex Ads для Android-сборки.

## Android (Capacitor + Yandex Mobile Ads)

Веб-часть уже содержит мост: компонент `src/components/game/AdOverlay.tsx`
экспортирует `isNativeYandexAds()` и `showRewardedAd(blockId)` — они вызывают
`window.Capacitor.Plugins.YandexAds` (loadRewarded / showRewarded / события
`rewardedAdEvent`). В вебе (без Capacitor) автоматически показывается демо-ролик.
Нативная Android-обёртка с плагином YandexAds подключается отдельно при сборке APK/AAB.
