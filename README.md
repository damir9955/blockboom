# Block Boom / Блок Бум — Blast Block Puzzle

Мобильная головоломка (жанр Block Blast / Toon Blast): поле 8×8, фигуры из блоков,
тикающие бомбы с круговым фитилём, камни-препятствия (разбиваются со 2-го удара),
50 уровней с 1-3 целями и лимитом ходов, звёзды, монеты, бустеры, магазин в игре,
пополнение монет за просмотр рекламы (демо в вебе, нативно — Yandex Mobile Ads).
Главное меню с ежедневным подарком, справкой и настройками. **Бесконечный режим:**
задачи появляются, выполняются и сразу сменяются новыми без остановки — играть,
пока фигуры помещаются; в конце — счёт и рекорд. Языки: RU / EN (автодетект +
переключатель). Полностью работает офлайн (PWA).

**Графика 1.8.0 — «реалистичный глянец»:** объёмные леденцовые блоки с бликами,
фасками и микротекстурой (спрайт-кэш на canvas), доска-лоток с гнёздами и
студийным светом, стеклянная полка фигур, светящиеся частицы, стеклянные
чипы задач с прогресс-барами, «сочные» 3D-кнопки с прожимом, реалистичная
иконка приложения и арт-фон меню (AI-арт), PWA-иконки перерисованы.

## Запуск локально

```bash
bun install        # или npm install
bun run dev        # http://localhost:3000
```

## Деплой на Vercel (5 минут)

1. Создай репозиторий на GitHub и запушь этот код:
   ```bash
   git init
   git add .
   git commit -m "Block Boom 1.8.1"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/blockboom.git
   git push -u origin main
   ```
   **Обновление через веб-интерфейс GitHub (без консоли):** открой репозиторий →
   **Add file → Upload files** → распакуй архив → зайди ВНУТРЬ папки → Ctrl+A
   (выделить всё, включая папки `src` и `public`) → перетащи в зону загрузки
   (браузер Chrome или Edge — Firefox не загружает папки) → Commit changes.
   В превью коммита должно быть видно десятки изменённых файлов из `src/` и
   `public/` — если только 2-3 файла из корня, папки не доехали: повтори.
2. Зайди на vercel.com → **Add New… → Project** → выбери репозиторий → **Deploy**
   (настройки менять не нужно: Next.js определится автоматически).
3. Получишь адрес вида `blockboom-xxx.vercel.app` — это и есть адрес игры
   (HTTPS уже включён, манифест, офлайн и иконки внутри).

## assetlinks.json (после упаковки в PWABuilder)

Когда соберёшь Android-пакет на pwabuilder.com, там покажут SHA-256 отпечаток
твоего ключа подписи. Создай файл `public/.well-known/assetlinks.json`
(шаблон — `assetlinks.example.json` в корне, подставь свой package_name и SHA),
закоммить и запушь — Vercel перепубликует сайт, и приложение будет
открываться без адресной строки.

## Никогда не коммить

- `.env` и любые ключи
- keystore / пароль от него (это подпись приложения — храни отдельно!)

## Что нового в 1.7.0

- **Бесконечный режим без остановки:** задачи появляются, выполняются и сразу
  сменяются новыми — без экранов «уровень пройден», поле и счёт не сбрасываются.
  Сложность ходит волнами 1→5 и снова с 1 (как в маджонгах), изредка (каждый 10-й
  набор) — сразу 4 задачи. Поставленная фигура сразу заменяется новой.
  Ходов нет — играем, пока фигуры помещаются или не одолели бомбы.
  В конце: счёт, число выполненных задач и рекорд (localStorage), бейдж
  «Новый рекорд!». Монеты в этом режиме не начисляются.
- Камни для цели «камни» появляются безопасно — всегда остаётся место для фигур.

## Android (Capacitor + Yandex Mobile Ads)

Веб-часть уже содержит мост: компонент `src/components/game/AdOverlay.tsx`
экспортирует `isNativeYandexAds()` и `showRewardedAd(blockId)` — они вызывают
`window.Capacitor.Plugins.YandexAds` (loadRewarded / showRewarded / события
`rewardedAdEvent`). В вебе (без Capacitor) автоматически показывается демо-ролик.
Нативная Android-обёртка с плагином YandexAds подключается отдельно при сборке APK/AAB.
